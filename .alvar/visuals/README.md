# Visuals

Diagrams generated by the `learn-visual` skill.

Supported: Mermaid (in maps/sessions), HTML previews, SVG, LaTeX in Markdown.

Use `preview_markdown` or `preview_html` so the learner sees rendered output in a browser, not a raw fence. Keep the source `.md` / `.svg` / `.html` here so the vault stays durable.

Do not generate a picture because the system can. Generate one when it locks a step.
